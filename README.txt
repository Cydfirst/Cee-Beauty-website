HOW TO PUBLISH FREE USING YOUR IPHONE
Think of this ZIP as a packed folder. Unzip it, upload the three website files to GitHub, then switch on GitHub Pages.

1. DOWNLOAD AND UNZIP
- Tap the ZIP download link and choose Download if asked.
- Open the iPhone Files app > Downloads.
- Tap cee_beauty_custom_website_updated.zip once.
- Open the unzipped folder. You should see index.html, style.css, script.js, and README.txt.

2. MAKE A FREE GITHUB ACCOUNT
- Open Safari and go to https://github.com/
- Sign in or create an account.
- If the page is awkward on iPhone, tap Safari's aA button and choose Request Desktop Website.

3. CREATE THE ONLINE WEBSITE FOLDER
- Go to https://github.com/new
- Name the repository: cee-beauty-website
- Choose Public, then tap Create repository.

4. UPLOAD THE WEBSITE FILES
- Open your new repository and choose Add file / Upload files (you may need the + menu or Desktop Website view).
- Upload index.html, style.css, and script.js.
- Make sure they are directly in the repository's main area, not inside another folder.
- Tap Commit changes or the save button.

5. TURN ON FREE HOSTING
- Open repository Settings, then Pages.
- Choose Deploy from a branch.
- Choose branch main and folder / (root), then tap Save.
- Wait a few minutes and return to Settings > Pages.
- Open the website address GitHub shows. It should look like https://YOUR-USERNAME.github.io/cee-beauty-website/

6. TEST IT
- Open the link on your iPhone.
- Tap a service and check that WhatsApp opens with a message ready.
- Check the phone number, prices, Instagram link and address before sharing.

IF SOMETHING GOES WRONG
- For a 404 page, confirm index.html is directly in the repository's main area and Pages is set to main / (root).
- If edits do not show immediately, refresh or wait a few minutes.
- You can update prices later by editing index.html in GitHub and saving/committing the change.

You do not need to buy a domain or pay a website builder to start. GitHub Pages gives you a free website address ending in github.io.
